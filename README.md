# 炸金花游戏 (AI Jinhua)

一个基于Go语言开发的炸金花游戏，支持多人在线对战，具有完整的游戏规则和流畅的游戏体验。

## 功能特点

- 🎮 **完整的炸金花游戏规则**：支持闷牌、看牌、跟注、加注、弃牌、比牌等操作
- 👥 **多人在线对战**：支持多玩家同时在线游戏
- 🏠 **房间系统**：房主创建房间，其他玩家加入
- 💬 **实时聊天**：游戏中支持玩家聊天
- 📊 **游戏统计**：显示每局获胜者和获胜金额
- 🔒 **安全可靠**：使用TCP协议通信，确保游戏数据安全

## 游戏规则

### 基本规则

1. **牌型大小**：豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张
2. **特殊规则**：235 > 豹子（可通过代码配置开关）
3. **游戏流程**：
   - 每人发3张牌
   - 轮流出牌，可选择：闷牌、看牌、跟注、加注、弃牌、比牌
   - 最后剩下的玩家获胜，获得奖池中的所有筹码

### 牌型说明

| 牌型 | 说明 | 示例 |
|------|------|------|
| 豹子 | 三张相同点数的牌 | AAA, 222 |
| 顺金 | 同花顺，即同花色的顺子 | A♠K♠Q♠, 5♦4♦3♦ |
| 金花 | 同花色的三张牌 | A♠K♠J♠, 2♦5♦8♦ |
| 顺子 | 点数连续的三张牌 | A23, KQJ |
| 对子 | 两张相同点数的牌 | AA2, KK5 |
| 单张 | 不符合以上牌型的牌 | A35, K24 |

### 操作说明

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 看牌 | `k` | 查看自己的手牌 |
| 闷注 | `b 金额` | 不看牌直接下注 |
| 跟注 | `c` | 跟上当前的下注金额 |
| 加注 | `r 金额` | 增加下注金额 |
| 弃牌 | `f` | 放弃当前手牌，退出本局游戏 |
| 比牌 | `v id` | 与指定ID的玩家比牌 |
| 退出 | `exit` | 退出房间或游戏 |

## 命令说明

### 大厅命令

| 命令 | 说明 |
|------|------|
| `ls` | 刷新房间列表 |
| `n` | 创建新房间 |
| `j id` | 加入指定ID的房间 |
| `exit` | 退出游戏 |

### 房间内命令

| 命令 | 说明 |
|------|------|
| `s` | 房主开始游戏 |
| `k` | 看牌 |
| `b 金额` | 闷注 |
| `c` | 跟注 |
| `r 金额` | 加注 |
| `f` | 弃牌 |
| `v id` | 比牌 |
| `exit` | 退出房间 |

## 游戏流程示例

```
1. 玩家A创建房间，成为房主
2. 玩家B和玩家C加入房间
3. 房主输入`s`开始游戏
4. 系统发牌，每人3张
5. 玩家轮流出牌：
   - 玩家A：闷注10筹码
   - 玩家B：跟注10筹码
   - 玩家C：看牌后加注20筹码
6. 游戏继续，直到剩下最后一名玩家
7. 系统显示获胜者和获胜金额
8. 下一局游戏开始
```

## 开发说明

### 主要模块

1. **服务器模块** (`server.go`)：处理客户端连接、房间管理、游戏逻辑
2. **客户端模块** (`client.go`)：处理用户输入、游戏界面、网络通信
3. **房间模块** (`room.go`)：管理房间内的玩家和游戏流程
4. **游戏逻辑模块** (`judge.go`)：处理牌型分析、手牌比较
5. **协议模块** (`protocol.go`)：定义客户端和服务器之间的通信协议
